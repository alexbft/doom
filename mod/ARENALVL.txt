// Arena level configuration (read by ArenaLevelConfig in mod/zscript/levels.zs).
//
// Each press of the arena switch starts the next level: it spawns that
// level's monsters (away from the player), scatters its items around the
// arena and puts its weapon in the arena center. The switch only works once
// every monster is dead.
//
// Syntax (one directive per line, // or # starts a comment):
//   level                    start a new level block (levels go in order)
//   monster <Class> <count>  monsters to spawn
//   item    <Class> <count>  pickups (health, armor, ammo, powerups)
//   weapon  <Class>          the level's new weapon (at most one)
//   overflow_scale <x>       global: after the last level, the last level
//                            repeats with monster/item counts multiplied by
//                            1 + x * (levels past the end), without a weapon
//
// Class names are standard Doom actor names, e.g.
//   monsters: ZombieMan ShotgunGuy ChaingunGuy DoomImp Demon Spectre LostSoul
//             Cacodemon HellKnight BaronOfHell Arachnotron PainElemental
//             Revenant Fatso Archvile Cyberdemon SpiderMastermind
//   items:    HealthBonus Stimpack Medikit Soulsphere Megasphere
//             ArmorBonus GreenArmor BlueArmor
//             Clip ClipBox Shell ShellBox RocketAmmo RocketBox Cell CellPack
//   weapons:  Chainsaw Shotgun SuperShotgun Chaingun RocketLauncher
//             PlasmaRifle BFG9000
